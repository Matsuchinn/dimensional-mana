# r153 斗气招架、聚气表现、结界射线音效修复

适用：Minecraft 1.21.1 / NeoForge。更新前先备份世界，移走旧版同名 jar，只保留新版。

## 一、斗气招架（Parry）

主手拿**剑**、副手**空手**，**长按右键 5 刻（0.25 秒）**进入招架姿态：视角略微下沉，准心下方出现金色括弧，斗气过半时剑身附着一层发光粒子，并有一声拔刀出鞘的金属声。松开右键或换手立刻退出。

### 姿态本身

- 受到的所有伤害 **-10%**。
- 代价：每真正挨一下（实际掉血 > 0），主手剑掉 **1 点耐久**。

### 弹反（姿态下按左键）

冷却 **8 刻（0.4 秒）**，一次只结算一个目标。

| 情况 | 判定 | 消耗 |
| --- | --- | --- |
| 3.6 格内有敌对箭矢 / 火球 / 魔法弹 | 直接弹碎弹射物 | 2 点斗气 |
| 按下左键后 12 刻内挡下 3 格内敌对生物的近战伤害 | **普通招架** | 等于怪物攻击力的斗气 |
| 同一窗口，但伤害在 5 刻内到达 | **完美招架** | 同上，并返还 1.5 倍 |
| 斗气不足以支付攻击力 | **弹反失败** | 斗气全部清空 + 4 秒斗气溃散 |

- 普通招架：不受伤、不返还斗气、不打断怪物。
- 完美招架：打断怪物当前动作并**眩晕 1 秒**（不可移动 / 不可攻击），返还 1.5 倍消耗，净赚一半；**斗气已经满了**时溢出的部分换成 **2 秒速度 II**。
- 弹反失败：硬吃这一下，斗气清零并进入斗气溃散（全伤害易伤 25%、自己近战 -45%，持续 4 秒）。
- 弹反成功是「主动花斗气」，即使刚好把斗气花到 0 也**不会**算成斗气溃散。

### 视听反馈

- 举刀：拔刀出鞘声（`minecraft:item.armor.equip_chain` 高音调）。
- 普通招架：金属撞击声 + 爆裂的白色 / 金黄色火花，准心弹出白圈。
- 完美招架：十字形横扫冲击波 + 白闪 + 视野边缘金色光晕；「铛——！」的高频金属回响与沉闷的「咚」；怪物头顶冒眩晕星星与惊叹号。
- 弹射物弹反：箭矢是木屑铁屑，火球是「嗤」的熄灭声与火焰碎屑，冰是冰晶碎裂，奥术是紫色碎屑与波纹。
- 弹反失败：玻璃 / 护盾碎裂声，屏幕边缘泛红。

### 与其他系统的关系

- 姿态下右键不再放置方块、打开村民交易这类交互，左键也不会挖方块。
- 被定身（水牢、冰棺、眩晕）时无法维持姿态，会强制收刀。
- 死亡、掉线、换维度都会清掉姿态，不会把冷却带进下一局。

## 二、凝聚斗气的聚气表现

- 静止站定按住 Alt+Z 凝聚斗气时，身体周围会持续出现向中心收束的金色粒子，脚下也有斗气环。
- 每两秒补一声清亮的钟声，音调随斗气比例升高，越接近满槽越高。
- 粒子与音效都是服务端广播，其他玩家也能看到、听到。

## 三、多重结界射线：后续波次也出声了

之前只有法阵展开瞬间和第一波射击有声（法阵本身展开时的奥术音），之后每一波射击都是静音的。现在每一波射击都会响一发射线音效；九个法阵同一刻开火时只响一次，避免叠成噪音，但**下一波（三秒后）依然听得见**。
