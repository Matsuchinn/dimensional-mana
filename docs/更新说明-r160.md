# r160 斗气进阶系统与战斗手册

适用：Minecraft 1.21.1 / NeoForge。更新前先备份世界，移走旧版同名 jar，只保留新版。

这一轮把「斗气」从一层被动减伤，做成了一条完整的物理 / 剑士路线：独立的斗气等级、
六项斗气技能、三项斗气能力、两件斗气饰品，外加一本可以和《万法知识之书》配对的《战斗手册》。

## 一、新增创造物品栏「次元物语：斗气」

创造模式物品栏里多了一页，里面依次是斗气手套、剑士护符、战斗手册和三本斗气技能书。
原来「魔素」「魔法」「自然」三页的内容没有变，这些新物品不会重复出现在它们里面。

## 二、两件新饰品

### 斗气手套【手饰】

- 近战伤害 **+15%**，独立乘区：和锋利、力量、暴击各乘各的，不会被加算稀释。
- 近战命中恢复 **2 点斗气**；击杀生物的那一下翻倍，恢复 **4 点**。
- 合成：**魔晶加工台**，魔力布匹 ×2 + 金锭 ×3 + 粗制魔构件 ×1 + 中级魔晶 ×1，
  **600 魔素 / 20 秒**。九宫格里随便摆，按材料数量匹配。

### 剑士护符【护符】

- **自然恢复斗气 +1.0 点/秒**：戴上以后哪怕站着不动也在慢慢回斗气。
- 触发**完美格挡**时获得 **+25% 移动速度，持续 2 秒**，弹开以后能立刻贴上去追。
- 合成：**魔晶加工台**，金锭 ×2 + 铁块 ×2 + **任意一本斗气技能书** ×1，
  **800 魔素 / 30 秒**。

## 三、新物品：战斗手册（Combat Codex）

暗红色皮革封面，中央是交叉双剑徽记，和蓝色魔法阵的《万法知识之书》正好成对。
**首次进入世界时和魔素之书一起发放**，右键翻看，也可以随时按手册里的页签来回切。

### 书签 1：基础战斗信息

实时读取玩家当前属性和装备，展示物理面板：

- 生命值（当前 / 上限）、护甲值、韧性。
- 斗气值（当前 / 上限，带进度条）、斗气恢复速度（点/秒）。
- 近战基础伤害、近战伤害加成（装备与技能的独立乘区）、攻击速度、暴击率、暴击伤害。
- 目前「处决」的斩杀阈值。
- 防御面板：完美格挡判定窗口（5 tick）、招架伤害减免（基础 10% + 钢铁壁垒）、
  招架破绽易伤（基础 +75% + 见切）。

### 书签 2：斗气与技能加点

- **斗气等级独立于魔法等级**：上限 15 级，升级曲线和魔法等级完全相同（64 × 2^等级）。
- 经验来源：造成近战伤害 **每 1 点给 1 点经验**、击杀生物 **+10**、完美格挡 **+20**。
- 升级发**斗气技能点**（起始 6 点，发放档位和魔法一样），只能花在下面六项技能上。
  每项最高 20 级，每 3 级加 1 点消耗、最高 4 点，和魔法技能完全一致。

| 斗气技能 | 每级效果 |
| --- | --- |
| 斗气强化 | 斗气上限 +10 点 |
| 钢铁壁垒 | 招架姿态的减伤 +2%（基础 10%） |
| 见切 | 完美格挡后敌人的易伤 +5%（基础 +75%） |
| 回气 | 每秒主动斗气恢复 +0.2 |
| 剑气精通 | 剑气类技能伤害 +5%（独立乘区） |
| 处决 | 对生命值低于 1%/级的生物造成伤害时必定暴击 |

### 书签 3：能力

三项斗气能力，靠对应的技能书解锁，**没有冷却**，只按斗气收费：

| 能力 | 消耗 | 效果 |
| --- | --- | --- |
| 拔刀斩 | 30 斗气 | 收刀蓄力 0.5 秒，向前方 5 格挥出 120° 扇形剑气，造成 0.8×武器基础伤害+2 物理伤害并击飞 4 格 |
| 瞬步 | 20 斗气 | 朝准心方向瞬间移动 6 格，可以朝天上瞬；碰到方块会停在障碍前 |
| 剑气附加 | 40 斗气 | 下一次近战攻击额外附加一段 1.5×武器基础伤害+2 的无视护甲物理伤害（10 秒内有效） |

武器基础伤害读取的是玩家当前攻击力，所以**锋利、力量这些加成都算在里面**。

## 四、技能书怎么拿

- 三本书分别是：**拔刀斩技能书**、**瞬步技能书**、**剑气附加技能书**，都是独立物品。
- 主要来源：**完美格挡后击杀处在破绽里的生物，有 5% 概率掉一本随机的技能书**。
- 右键研读永久解锁；已经会了的技能书不会被吃掉，可以留着当剑士护符的材料。
- 学会的能力会自动装进第一个空槽，马上就能用。

## 五、操作

| 操作 | 默认按键 |
| --- | --- |
| 打开斗气技能盘并选择 | **按住 Alt + 鼠标键 5**（也可以直接按鼠标键 5） |
| 施放当前选中的斗气技能 | **点按 Alt**（按下再松开时触发） |
| 技能盘里左键选槽 / 右键清槽 | 鼠标左键 / 右键 |

施放走的是「松开 Alt」那一刻，所以 Alt + Z 凝聚斗气、Alt + 左键追加法术这些组合不会被顺手丢出技能。
两个键都可以在「选项 → 控制」里改绑。

## 六、位置（排查用）

- `QiProgression.java`：斗气等级、经验、技能点、六项技能、三项能力与快捷盘存档。
- `QiSkills.java`：拔刀斩 / 瞬步 / 剑气附加的服务端结算，以及击杀掉书、完美格挡加成、自然恢复。
- `CombatCodexScreen.java` / `QiWheelScreen.java`：战斗手册三页界面与斗气技能盘。
- `ManaEvents.java`：近战命中攒经验、回气、手套增伤；登录发手册；每 20 tick 同步斗气进度。
- `BattleQiParry.java`：钢铁壁垒的减伤、见切的易伤、完美格挡 +20 经验与护符加速。
- `CrystalProcessorBlockEntity.java`：两条加工台配方与「任意斗气技能书」的匹配。

## 七、怎么验证

1. 新建世界进游戏，背包里应该同时有《万法知识之书》和《战斗手册》。
2. 右键《战斗手册》，按 Alt 键切页签，三页都能翻；加点按钮点了以后斗气技能点会减少。
3. 创造模式拿一本拔刀斩技能书右键，再按住 Alt + 鼠标键 5 打开技能盘，装进 1 号槽。
4. 点按 Alt 放拔刀斩：先听到收刀声，0.5 秒后前方扇形范围内的怪被打飞。
5. 戴上斗气手套随便打几只怪，血条下方的斗气 HUD 会涨；戴剑士护符站一会儿，斗气也会慢慢回。
6. 完美格挡后立刻击杀的怪有 5% 概率掉技能书（多打几次能看到掉落特效）。

## 八、没变的部分

法术、元素反应、哥布林、冒险者、雨靴、交易和其他机器都没有改动。当前版本号仍是 1.2.0。
