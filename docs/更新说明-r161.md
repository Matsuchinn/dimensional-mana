# r161 斗气轮盘改键、HUD 收尾与手册文案修复

适用：Minecraft 1.21.1 / NeoForge。更新前先备份世界，移走旧版同名 jar，只保留新版。

这一轮只做三件小事，都是上一轮斗气系统的收尾。

## 一、斗气技能盘默认按键改成大小写锁定键

- 原来默认绑在「鼠标键 5」，现在默认是 **大小写锁定键（Caps Lock）**，按住开、松开就关。
- 老存档里还留着旧默认值的话，进游戏后会自动换成大小写锁定键，并写回 `options.txt`；
  自己改过的按键不会被改动。
- 想换别的键：`选项 → 控制 → 按键绑定 → 次元物语` 里改「打开斗气技能盘」。
- 施放斗气技能仍然是点按左 Alt（可在同一页改绑）。

## 二、左下角的斗气提示板换成小图标

- 原来左下角是一块 66×32 的提示板，上面写着技能名、消耗和施放键，会压住魔素球和法术图标。
- 现在只剩一个 **18×18 的技能图标**：有选中法术时，它排在「按 X 施法」那行字后面；
  没选法术时直接放在法术图标的位置。两种情况都不会和法术 HUD 重叠。
- 「按 X 打开斗气技能盘」这行新手提示已经去掉，需要看技能盘直接按大小写锁定键。

## 三、战斗手册里的英文码修好了

- 战斗手册第三页「能力」的说明文字、以及斗气技能盘里挑能力的小卡片，
  之前因为漏了翻译键，会直接显示 `gui.dimensional_mana.qi_manual.iai_slash.1` 这样的英文码。
- 现在三条能力的中文说明都补齐了：拔刀斩、瞬步、剑气附加。
- 顺手把技能加点页的按钮文字也换成了中文：升级按钮显示「+2 点」，满级显示「满级」。
