# r149 生物暴击系统 + 二十三件新饰品（含哥布林挥臂修正）

适用：Minecraft 1.21.1 / NeoForge。更新前先备份世界，移走旧版同名 jar，只保留新版。

## 一、生物暴击：难度决定概率与倍率

所有生物的**近战命中**（贴脸打，不含箭和法术弹道）都会按世界难度掷一次暴击：

| 难度 | 暴击率 | 暴击伤害 |
| --- | --- | --- |
| 和平 | 0% | 1.0 倍 |
| 简单 | 5% | 1.25 倍 |
| 普通 | 10% | 1.5 倍 |
| 困难 | 15% | 1.75 倍 |

关键点是**判定位置**：写在 `LivingIncomingDamageEvent`（挨打的第一步），比护甲、抗性、斗气减伤都早。
所以暴击是"这一下打得更重"，而不是绕开防御的额外伤害 —— 护甲越厚，暴击带来的绝对差值越小。

玩家同样吃这套判定：原版跳劈（下落中、不疾跑、不失明…）照旧由原版乘 1.5 倍并记为暴击，
这里只补上它没有的部分，也就是"平地近战也能按难度暴击"。系统会记住"这一下是不是暴击、
打了多少"，供饰品读取（风险手镯的重掷、无名护符的暴击抗性、力量护符的力量都靠这份记录）。

配置文件是 `config/dimensional_mana-critical.toml`，四个难度各一组，另有三个开关：

```toml
[critical]
  enabled = true                 # 整套系统总开关
  player_attacks_can_crit = true # 玩家近战是否参与
  show_effects = true            # 暴击粒子与音效
  [critical.peace] chance = 0.0  damage = 1.0
  [critical.easy]  chance = 0.05 damage = 1.25
  [critical.normal] chance = 0.10 damage = 1.5
  [critical.hard]  chance = 0.15 damage = 1.75
```

三个"独立乘区"的实现方式说明一下，免得以为是叠加错误：

- 绿琥珀戒指用 `ADD_MULTIPLIED_TOTAL` 改移动速度，是"最终速度 ×1.25"；
- 嗜血胸针 -25%、奥萝菈 -35% 也是 `ADD_MULTIPLIED_TOTAL`，作用在最大生命上，互不覆盖；
- 受伤侧的 -5%、×0.5、×1.35 这类乘区按声明顺序逐层相乘，每次只改"当前金额"，不会回到原始伤害。

## 三、获取途径

宝箱规则走 `LootTableLoadEvent` 往原版表里加独立池子（概率互不干扰），一处写错不会影响原掉落：

- 村庄/沉船宝箱 10% → 走私之戒；雪地小屋 12% → 月光祝福；沙漠神殿 4% → 炽阳恩赐；
  废弃矿井/地牢 8% → 迷失护符；下界要塞 8% → 嗜血胸针；远古城市 33% → 全知残页；
  远古魔法祭坛 25% → 抉择戒指；
- **沼泽群系**里任何结构宝箱 10% → 剧毒指环（用 `LootItemCondition` 读开箱位置的生物群系）；
- 考古式彩蛋：大型魔晶洞穴的纯态液态魔晶池底埋了一口宝箱，主产中级魔晶粉、各类补魔剂 1~3、
  紫水晶碎片 3~8，另有 3% 元素吸收护符。箱子的位置是"从中心竖列往下找第一个液态魔晶方块"，
  找不到就在 ±2 格范围内再找，`tools/check_relic_cache.py` 用 400 个随机洞穴验证过定位。

生物掉落：哥布林首领 15% 绿琥珀戒指、毒元素史莱姆 1% 剧毒指环、铁傀儡/劫掠兽 10% 力量护符、
夜间幻翼 5% 月光祝福、哥布林萨满 10% 与女巫 15% 风险手镯、猪灵蛮兵 1% 嗜血胸针、
女巫/远古守卫者 5% 净化核心、凋灵必掉塞拉菲丝、末影龙必掉柯赛塔斯、远古守卫者 5% 奥萝菈、
监守者 10% 封魔眼罩、精英光元素史莱姆 10% 光辉核心。

无名护符的骷髅计数记在**击杀者自己**的持久数据里：困难模式下每累计 100 只骷髅，下一只被击杀的
骷髅 50% 掉落；换维度、重进都不清零。

合成（魔晶加工台，秒数 ×20 = 刻数）：万解手镯 3 个净化核心 / 200 魔素 / 15 秒；
法师之喜 奥术元素结晶 + 特级魔晶粉 ×3 + 魔法绸缎 ×2 / 800 / 30 秒；
万用腰带 特级魔晶 ×2 + 精致魔构件 + 魔法绸缎 ×4 / 5000 / 60 秒；
赤灵护符 五种头颅 + 龙首 / 3000 / 45 秒；天使王冠 光辉核心 + 附魔金苹果 + 金块 ×7 / 8000 / 90 秒；
全知全能残片 全知残页 ×3 / 10000 / 120 秒。

冒险者交易：如果刷出的报价里有稀有级别，会把其中一笔初级交易换成"16 极品魔晶 → 1 个侦探护符"。
走私之戒的半价在这里也生效 —— 展示格、够不够判定、真正扣材料走同一个 `discounted` 方法，
所以界面上的价格就是实际扣的数量。

## 五、修正：哥布林挥臂用的是废案模型

上一轮的挥臂动画改到了 `art/goblin_model/`，那是废弃版本；实装的是 `art/goblin_refresh/`，
而且预览图里手臂方向是反的。本轮修正：

- `tools/preview_goblin_swing.py` 改为读 `art/goblin_refresh/goblin_{kind}_equipped.bbmodel`；
- 方向反的根因是**坐标空间不同**：Java 里 `ModelPart.xRot` 取负值是手臂向前，
  而 bbmodel 的欧拉角在 X、Z 上与 Java 反号（Y 相同）。预览脚本现在统一做
  `rotation = [-x, y, -z]`，和游戏里看到的姿势一致；
- 挥臂曲线改成绝对角度的三段关键帧（抬手 → 下劈 → 收回），并新增两条断言：
  "最高点之后手臂不能甩到身后"（方向对了就甩不过去）、"下劈必须落到峰值以下"。
  `tools/check_goblin_poses.py` 跑过 10 组体型与主手组合；
- 废案 `art/goblin_model/`（14 个文件）与 `MAGIC_R26` ~ `MAGIC_R30` 的旧说明已删除，
  保留 R31 起的文档。

预览：`docs/previews/goblin_attack_swing.png`（1680×480，7 帧）。
