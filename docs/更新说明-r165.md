# r165 修 `/kill` 之后生物卡成幽灵：血条空、不动、打不死

适用：Minecraft 1.21.1 / NeoForge。更新前先备份世界，移走旧版同名 jar，只保留新版。

这一轮只修 bug，不改玩法数值。

## 一、现象

用 `/kill`（或其它模组、插件里等价的即死手段）打生物或玩家时，目标有可能**不死亡**：
血条是空的、模型还站在原地、不打人也不动，再打它也不掉血、不掉落、不消失。
退出重进还在。

## 二、原因

`/kill` 用的伤害叫 `generic_kill`，数值是 `Float.MAX_VALUE`（浮点数能表示的最大值，约 3.4×10³⁸）。
本模组的伤害链上有一大串乘区：暴击、斗气减伤、斗气溃散易伤、深层冻结易伤、元素抗性、
远古诅咒、杀手附魔、元素镀层、金钟罩、磐石外壳……

1. `Float.MAX_VALUE` 随便乘上一个大于 1 的系数（暴击 1.25~1.75、易伤 1.25、诅咒 3 倍……）
   就会**溢出成无穷大 `Infinity`**；
2. `Infinity` 再撞上任意一个 0 倍率（例如 100% 抗性、100% 魔法减伤、完全吸收），
   就会算成 **`NaN`（非数字）**；
3. `NaN` 被写进实体的生命值以后，`NaN <= 0` 是 false、`NaN > 0` 也是 false ——
   原版的死亡判定、死亡动画、存活判定**全部失效**，实体既不活着也不死掉，就卡成了幽灵。

所以这不是 `/kill` 本身的问题，是**本模组给必杀伤害乘倍率造成的**。原版自己的伤害链里
`Float.MAX_VALUE` 和 0 相乘只会得到 0（然后正常死亡），不会产生 `NaN`。

顺带修掉的两个相关问题：

- **`/kill` 被饰品吃掉**：戴「天使王冠」时它的庇护会把致命伤改成「只扣到剩 1 滴血」，
  全知全能残片会把整下伤害改成 0。结果 `/kill` 对这两个饰品完全无效。
- **护盾耐久变负数**：举盾时元素镀层的侵蚀量算法是「伤害 ÷ 10 + 1」，伤害是
  `Float.MAX_VALUE` 时强转整数会溢出，护盾耐久被算成负数。

## 三、修法

1. 新增 `LethalDamage`：认出「必杀伤害」（`generic_kill`，或数值在一百万以上、正常战斗不可能打出来的伤害）。
2. 在伤害链最前面把它的数值**收窄成 100 万点**：足够一击杀死任何生物（原版最大生命 1024，
   本模组最肉的生物也就几十万），又不会被后续几十倍乘区溢出。收窄以后即使被 100% 减伤乘以 0，
   结果也只是 0，不会再有 `NaN`。
3. 暴击、斗气、经验结算、饰品、元素镀层、金钟罩、磐石外壳等所有修正，遇到必杀伤害**一律跳过**。
   `/kill` 于是完全按原版走：正常死亡、正常掉落、正常进重生界面。
4. 加了一道**血量安全网**：每刻检查所有生物和玩家，谁的生命值是 `NaN`，就修正回 0 并补一次
   正常死亡（已经在死亡动画里的只修正数值，不会重复掉落）。旧存档里已经卡住的幽灵，
   装上新版本进游戏的第一秒就会被送回正常死亡流程。

## 四、改动的文件

- `LethalDamage.java`：新增。必杀伤害识别 + 数值收窄（`SAFE_LETHAL` = 100 万）。
- `ManaEvents.java`：受击、伤害结算前后都跳过必杀伤害；新增血量 `NaN` 安全网。
- `CriticalSystem.java`：必杀伤害不参与暴击掷骰。
- `RelicEffects.java`：必杀伤害不被天使庇护、全知残片拦截。
- `ElementPlating.java`：必杀伤害不结算盾牌侵蚀（防止耐久整数溢出）。
- `gradle.properties`：版本号 1.2.0-r165。
