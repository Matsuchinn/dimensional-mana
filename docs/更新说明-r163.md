# r163 末影龙复活：飞回龙巢、破绽期、越复活越强

适用：Minecraft 1.21.1 / NeoForge。更新前先备份世界，移走旧版同名 jar，只保留新版。

这一轮改的是原版末影龙：它被打空血条后**不再直接倒下**，而是进入「飞回龙巢 → 破绽期 → 复活」的循环，
每次复活都会更强。

## 一、被打空血之后：飞回龙巢

- 致命伤落下的那一刻，末影龙**不会死**：它会回血到「复活血量」、进入**无敌**状态，
  然后用两秒左右飞回龙巢（末地传送门）上方悬停。
- 飞行途中无论怎么打都不掉血，只会冒末地烛粒子。
- 龙巢位置按原版降落点算：末地传送门顶部再往上 2 格，站在传送门上用剑也够得着。
- 在别的维度召唤的末影龙没有龙巢，会在原地往上 3 格悬停。

## 二、复活破绽：只有这段时间能打

- 到巢后进入**破绽期**，这段时间它才会重新吃伤害，血量固定为「复活血量」。
- 破绽时长：**第一次 1 秒，之后每复活过一次 +2 秒**（1 → 3 → 5 → 7 …）。
- 破绽血量：**第一次 100 点，之后每复活一次少 15%**（100 → 85 → 72.25 …）。
- 破绽期里把血打完 = **真死**：末地传送门、龙蛋、经验和掉落全部照原版走。
- 破绽期里它的减伤体系整体失效：不套斗气减伤、不套 65% 总抗性、也不吃受击无敌帧，
  **100 血就是实打实的 100 点伤害**。不然默认配置下（5000 斗气 + 65% 总抗性 + 半秒无敌帧），
  1 秒的第一次窗口连两刀都砍不满，窗口等于没有。
- 破绽期结束还没打死 = **满血复活**，并且**生命上限 +15%**，然后回到正常的绕圈 / 俯冲战斗；
  下一次破绽会更容易打死，但它活着的时候也更肉。

## 三、提示与细节

- 开打时聊天栏提示「末影龙拒绝死亡，正飞回龙巢复活！」。
- 破绽开始时提示这次有几秒；破绽期间屏幕下方每秒倒数一次。
- 破绽结束提示这次复活后的生命上限。
- 复活全程关闭末地水晶的回血：水晶的 `heal()` 直接取消，水晶每 10 刻偷偷 `setHealth(+1)` 的那点回血也会被每刻压回去，免得破绽血量被柱子上的水晶补回去。
- 数据存在龙自己的持久化数据里，退出重进、服务器重启都能接上；用 4 颗末地水晶重新召唤的龙是全新的，从第一次（1 秒 / 100 血）重新算。
- `/kill`、`minecraft:generic_kill` 这类管理员手段仍然能直接送走它，方便清场。

## 改动的文件

- `DragonRevival.java`：新增。复活状态机（死亡拦截、飞回龙巢、破绽倒计时、复活加血上限、水晶回血关闭）。
- `GeneratedMod.java`：注册 4 个监听器（死亡、受击、治疗、实体 tick）。
- `ManaEvents.java`：死亡处理在事件被取消时直接返回（复活那一下不会白送斗气经验）；
  破绽期的末影龙按原始伤害放行，不吃斗气、总抗性、镀层与受击无敌帧。
- `zh_cn.json` / `en_us.json`：新增 5 条末影龙复活提示文案。
- `README.md`：生物章节新增「末影龙：拒绝死亡」。
- `gradle.properties`：版本号 1.2.0-r163。
