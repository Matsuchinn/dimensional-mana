# r156 完美招架后的「破绽」易伤

适用：Minecraft 1.21.1 / NeoForge。更新前先备份世界，移走旧版同名 jar，只保留新版。

## 一、完美招架那一秒，怪物变成「破绽」

以前完美招架只会把怪物定住 1 秒。现在这 1 秒同时是一个输出窗口：

- 被完美招架打晕的生物，身上会出现一个新的减益状态 **「招架破绽」**（英文 `Parried Vulnerability`），
  图标是一把断成两截的刀配橙红色冲击。
- 状态持续 **1 秒（20 刻）**，和眩晕时间完全重合；眩晕一结束，破绽也一起结束。
- 这 1 秒内，它受到的**所有**伤害都 **+75%**（也就是最终伤害 ×1.75）：
  近战、弓箭、法术、元素反应、刻蚀真伤都算，不是只加某一种。
- **不叠加**：无论你怎么连弹，它身上永远只有一层破绽，不会变成 +150%。
- **反复触发只刷新时间**：在破绽还没结束时再次完美招架，计时会重新回到完整的 1 秒，
  不会越叠越久，也不会提前消失。

## 二、怎么用

1. 主手拿剑、副手空着，长按右键进入招架姿态。
2. 怪物出手的一瞬间按左键，在 5 刻内挡下就是完美招架。
3. 听到「铛——」、看到怪物冒星星时，立刻反打，这一秒里的每一刀都是 1.75 倍。
4. 完美招架的判定、斗气返还、特效闪光、举刀姿势都和上一轮一样，没有改动。

## 三、实现位置（方便排查）

- `NewSpellContent.java`：新增 `parry_vulnerable` 状态效果。
- `BattleQiParry.java`：完美招架结算时挂上破绽，先摘后挂保证只刷新不叠加。
- `ManaEvents.java`：伤害结算最前面统一乘 1.75，所以全伤害类型都吃得到。
- `assets/dimensional_mana/textures/mob_effect/parry_vulnerable.png`：状态图标。
- 中英文 lang 都补了名字。
