# r155 完美招架闪光修好 + 招架姿势动画

适用：Minecraft 1.21.1 / NeoForge。更新前先备份世界，移走旧版同名 jar，只保留新版。

## 一、完美招架的 4 帧闪光现在真的会出现了

上一轮画的 4 帧闪光（把怪物「弹开」那一下）实际没显示出来：那段是当作世界里的立体贴片画的，
很容易被渲染阶段和渲染目标吃掉。这一轮换了做法：

- 每帧先把世界渲染用的矩阵记下来，把怪物换算成**屏幕上的坐标**，再在界面层直接贴那格 16x16 的图。
- 贴片跟着被打中那只怪物的头肩走：远处自动变小、贴脸自动变大，`8 刻`播完 4 帧后消失。
- 前 4 刻满亮度，后 4 刻淡出，还带一点点放大脉冲，看得清是「这一下被弹开了」。
- 实体中途消失就退回用服务端给的坐标画，不会整段不出现。

## 二、招架姿势：举刀抬到胸前

新增姿势动画，只在**举刀架势**（主手剑、副手空、长按右键进入）期间出现：

- **第三人称**：持剑那条手臂换成原版举盾的姿势——手臂收到胸前、跟着视线抬起，
  剑竖着举在身前，F5 看自己、或者看队友都是这个样子。
- **第一人称**：原来刀斜挂在右下角，现在绕刀自身转到横，再整体抬到胸前，
  变成「横刀架势」；刀身不会因为旋转被甩出画面。
- 弹反按左键时那一记**挥砍照样会挥出去**，不影响看得见挥刀。
- 松开右键、换手、副手拿东西、被定身，姿势立刻收回。

## 三、联机同步

进出姿态时服务端会给附近玩家的客户端发一个轻量通知，所以：

- 联机时别人也能看到你举起刀、收起刀。
- 自己那边仍以按键为准，不会被自己的回包顶掉。
- 换维度后记录会清空，不会把上一个世界的实体 id 认错。

死亡只回一半——这些改动照旧生效。
