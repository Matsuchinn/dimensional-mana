# r151 塞拉菲丝之护符：随机元素附伤会附着元素

适用：Minecraft 1.21.1 / NeoForge。更新前先备份世界，移走旧版同名 jar，只保留新版。

## 一、塞拉菲丝之护符

- 造成伤害时附加的那段 **1%~15% 随机元素伤害**，现在会走真正的元素伤害流程：先给目标挂上**对应元素的附着**，再结算伤害。
- 附着时长和普通元素伤害一致：吃元素结晶戒指 / 元素强化戒指的附着加成；戴上对应戒指时，这段附伤也吃该元素的伤害加成。
- 目标身上已经有别的元素时，这段附伤会按同一套优先级**触发元素反应**（蒸发、融化、超载、感电、冻结等），反应后的伤害才真正落地。
- 因为走的是「已结算元素伤害」通道，这段附伤本身不会暴击、不再吃刻蚀附伤，不会靠护符刷出连锁暴击；一次命中只结算一次饰品效果。
- 冷却仍是 **5 刻**，附伤数值区间不变。

## 二、提示框

- 描述改为「造成伤害时附加 1%~15% 随机元素伤害，并附着该元素（冷却 5 刻）」。

## 三、怎么试

- 戴上塞拉菲丝之护符，对着同一只怪连续攻击：状态栏会出现随机元素的附着图标，连续命中不同元素时会弹出元素反应提示。
- 想稳定观察反应，可以先用任意元素法术给目标挂一个元素，再近战触发塞拉菲丝。
