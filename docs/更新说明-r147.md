# r147 聚落规模、营帐细节与两处战斗数值

适用：Minecraft 1.21.1 / NeoForge。更新前先备份世界，移走旧版同名 jar，只保留新版。

## 一、"开新档全是小型聚落"：不是没写，是被选址门槛筛掉了

生成代码里三档一直都在（`GoblinCampStructure.findGenerationPoint`），但每一档都要先过一道地形门槛：
9×9 个采样点，总高差 ≤ 8、相邻采样点高差 ≤ 3、任何一个采样点碰到水面就直接否掉。

问题出在采样间距上：采样点固定 81 个，占地越大间距越宽（小型 6 格、大型 10 格）。
同一片丘陵，在大型营地的网格上量出来的相邻高差和总高差都更大，于是同一套容差把中型、大型反复拒掉。
再叠上原来的五/三/二抽签，实际见到的基本只剩小型。

改法：

- **容差按档位放大**：相邻高差 3 / 4 / 5 格，分位数总高差 8 / 10 / 12 格，允许的水面采样点 2 / 3 / 4 个。
- **总高差改成分位数高差**（掐掉最高、最低各 10% 的采样点）：一个山头或一个坑不再一票否决整块地；
  真正崎岖的地形照样算不过（山地大型的通过率仍然只有 2.9%）。
- **抽签改成四/三/三**（小型 40%、中型 30%、大型 30%）。

离线统计（`tools/check_goblin_camp_sizes.py`，同一份门槛代码 + 固定种子的分形噪声地形，每种地形 4000 次）：

| 地形 | 修复前实际见到 | 修复后实际见到 |
| --- | --- | --- |
| 平坦 | 小 65% / 中 25% / 大 10% | 小 49% / 中 28% / 大 22% |
| 丘陵 | 小 71% / 中 23% / 大 7% | 小 54% / 中 28% / 大 19% |
| 山地 | 小 98% / 中 2% / 大 0% | 小 62% / 中 25% / 大 13% |

门槛只影响**还没生成**的聚落；已经落地的营地不会变大变小。

## 二、营帐：灯笼、门框、门廊柱

- **灯笼**原本压在门廊右边那根支柱顶上，看着像把帐篷框架拆了一块。现在挂在屋脊正下方、门框正中：
  门廊内 3 格高、正对门口，从屋脊的横木垂下来，不再贴着柱子。
- **补上门框木头**：门洞两侧各立一根原木门框柱（高 3 格），顶上再补一根横梁，
  布墙上的开口收成一圈木头，门的轮廓清楚了。
- **门廊木柱下沉一格**：以前柱子底端和地基齐平，坡地或营地边缘的柱脚会悬在空气里。
  现在柱子从地面往下一格开始，插进土里，坡地上也不会浮空。

## 三、领主营帐的出入口不再被地形堵住

首领是 2.30 格高，门廊横梁下面只剩三格净空。原来的入口缓坡固定五格、每格可以差好几格，
帐篷正好落在坡脚时，门口第一格就要抬两格——站在横梁底下起跳必然撞头，首领就被自己家门槛卡住了。

现在：

- 门口**两格**与室内严格齐平，抬降从第三格（已经出了门廊顶）才开始；
- 之后每格最多 ±1 格，最多走八格，一路跟到自然地面，高出来的地形顺带挖掉；
- 离线自检用 BFS 走一遍"首领从营帐走到门外"：脚下要有方块、身上三格净空、抬一格要求四格净空。

## 四、地下巢穴的浮空南瓜

巢穴靠南墙的第二只南瓜原本摆在 `LAIR_STAND + 1`，下面什么都没有，浮在半空。现在放在地面南瓜旁边。

## 五、两处数值

- **首领【蓄力斩击】**：命中伤害从攻击力的 2.0 倍提高到 **6.0 倍**（仍然吃难度倍率，仍有一半概率眩晕 2 秒）。
- **铁傀儡【精准打击】眩晕**：70 刻（3.5 秒）缩短到 **36 刻（1.8 秒）**，且**不可叠加**：
  已经处在眩晕里的目标不会再被续时，连续命中不会把眩晕越拖越长。

## 六、破损弓的手持角度

对照原版 `minecraft:item/bow` 的 display 参数，第一人称原来多写了 `-12` 的 X 轴旋转、位移也高了 0.2，
所以拿在手里是往下歪的。现已改回原版角度 `[0, -90, 25]` / 位移 `[1.13, 3.2, 1.13]`；
第三人称本来就与原版一致，未改。顺带把拉弓换图的两个阈值（0.2 / 0.45）改回原版的 0.65 / 0.9，
之前刚拉开一点就摆出拉满的样子。

## 验证范围

- `tools/preview_goblin_camp.py`：三档 × 五种地形（平坦 / 单向坡 / 斜向坡 / 洼地 / 台地）共 15 组，
  跑的是真实的 `GoblinCampPiece.postProcess`。检查项：分区块生成一致、存档往返一致、首领站位、
  **首领能否走出营帐**、宝箱与封顶、垃圾池空位、**无悬空木柱与南瓜**、**门框灯笼居中且不在柱顶**、
  地下牢笼与竖井。
- `tools/check_goblin_camp_layout.py`：3000 个布局的必备建筑、屋檐间距、路网连通、大门数量、围墙边界。
- `tools/check_goblin_camp_sizes.py`：三档选址通过率统计（上表）。

以上是代码与离线结构验证，不代表已在整套模组环境里完成实机复测。
