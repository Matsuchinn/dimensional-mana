# r150 饰品专属贴图 + 栏位与效果修正

适用：Minecraft 1.21.1 / NeoForge。更新前先备份世界，移走旧版同名 jar，只保留新版。

## 一、十六件饰品换成专属贴图

上一轮二十三种新饰品里有十六种还在用「共用底图 + 染色层」的通用模板，这一轮全部单独画了 16×16 的专属图标：

- **t0**：赤灵护符（红 + 银白）。
- **t1**：塞拉菲丝之护符（紫）、柯赛塔斯之护符（粉蓝）、奥萝菈之护符（金 + 红）、封魔眼罩、法师之喜、元素吸收护符、侦探护符。
- **t2**：炽阳恩赐、风险手镯、抉择戒指、无名护符、迷失护符、嗜血胸针、万解手镯。
- **t3**：绿琥珀戒指、走私之戒、剧毒指环、力量护符、月光祝福。

元素结晶戒指（火/水/冰/雷/风/土/自然/金属/光/毒/音/奥术）仍然共用元素戒指底图 + 染色，这是它们「一眼看出元素」的设计。

## 二、胸口栏位修正

嗜血胸针回到 Curios 原本的 **body（胸饰）** 栏位，和披风共用 1 格；不再额外生成一个叫 `brooch` 的新栏位，也不会在饰品面板里显示英文 `brooch`。

## 三、天使王冠：正面效果 → 最大生命

- 仍然不会获得正面 Buff；每次获得正面效果改为 **最大生命 +10%**（按不含王冠加成的当前最大生命计算）。
- 总加成上限 **+25%**；脱下王冠立即收回，并避免留下超出上限的血量。
- 新增的这部分会同步补满，手感和以前的临时生命接近，但现在是真实的血上限。

## 四、万用腰带：通用饰品栏

- 万用腰带不再只加一个护符栏，而是加 1 格 **通用饰品栏（universal）**。
- 任何新饰品都能放进去并正常生效：属性加成、每刻效果、命中/受击触发都走同一套逻辑。
- 该栏位默认 0 格，只有戴着万用腰带时才出现。

## 五、哥布林装备更丰富

- 幼崽、战士、弓箭手、萨满出生时随机选择：不穿甲、布甲或铁甲，并且每件护甲还会单独随机缺省。
- 于是营地里会同时出现「基础哥布林模型」「只戴头盔」「布甲」「铁甲」等多种外观，不再清一色穿满。
- 首领保持全套铁甲 + 附魔，作为首领辨识度。

## 六、聚落与女巫

- **哥布林小屋的床**：地毯通道给羊毛床让路，窄小屋不会再出现床被地毯顶掉 1~2 格。
- **游离女巫**：恢复原版女巫的高额魔法抗性，带 `witch_resistant_to` 标签的魔法伤害只吃 15%（减免 85%）。

## 七、饰品效果补齐与描述精简

审查二十三种饰品的效果时修掉了几处实际失效的地方：

- **奥萝菈之护符**：远古守卫者的 5% 掉落以前被前面的分支用掉同一个随机数，永远拿不到；现在每件掉落独立掷骰。
- **净化核心**：女巫身上的 5% 掉落同样被前面的风险手镯分支拦截，已修复。
- **走私之戒**：猪灵以物易物改为在右键交易时给猪灵打时间戳，物品真正扔出时再翻倍；不再依赖「猪灵主手拿着金锭」这个永远不成立的判断。
- **赤灵护符**：击杀回血严格等于该次伤害的 100%，不再被自身「生命恢复 +15%」放大成 115%。
- **万解手镯**：3 秒以内的负面效果也会被缩短 15%，不再跳过。
- **月光祝福 / 炽阳恩赐**：昼夜加成只在主世界判定，下界和末地不会出现「夜晚增伤常驻、白天增伤永远不触发」。

提示框描述压缩成一句话一条；梯度归属、独立乘区、吸血结算方式等细节移到《万法知识之书》的「暴击与新饰品」页，共 18 行。

## 八、怎么拿到

- 宝箱、生物掉落、加工台配方等获取途径不变，上一轮的表格仍然有效。
- 调试：`/give` 或 `/curios add universal 玩家名 1` 可以直接试通用饰品栏。
