# r146 哥布林群体行为与地下巢穴

适用：Minecraft 1.21.1 / NeoForge。更新前先备份世界，移走旧版同名 jar，只保留新版。

## 地下空腔的成因

不是结构代码挖出来的。营地结构 JSON 里的地形适配是 `terrain_adaptation: "beard_thin"`，
而结构包围盒的下沿比营地地面低了 12 格（`GoblinCampStructure` 里的 `min - 12`）。
原版 `Beardifier` 对 `beard_thin` 的算法是：以包围盒下沿为基准，向上约 12 格范围内给地形密度加负值，
也就是把这层挖空，好让结构地面显得平整。

营地真实地面在下沿上方 11～19 格，所以这层被挖空的位置正好整片落在营地地板下面，
形成一块「跟着聚落走、深度固定」的地下空腔。地表以下 6 格是补土，所以从上面看不出来，挖下去才会掉进空腔。

## 将计就计：地下巢穴

这次直接把这层空腔做成正式的地下室，并把多余空隙封住：

- 领主营帐正下方是大厅：砂土、沙子、腐殖土、灰化土、砂砾和泥混合的地面，原木立柱、云杉顶板。
- 大厅正中一排云杉木栅栏牢笼（小型 2 个、中型 3 个、大型 4 个），带栅栏门和木板笼顶。
  笼里关着村民、铁傀儡，以及随机出现的悦灵、狗、猫、鹦鹉、鸡、羊、猪；会飞的囚徒关掉 AI，飞不出笼顶。
- 靠墙堆放干草块、南瓜、西瓜、木桶、工作台和一张新的「地下贮藏箱」（食物类战利品表）。
- 领主营帐地板上一扇云杉活板门，梯子竖井直通大厅；再挖 L 形地道通到最近的一到两间普通小屋，
  这些小屋里也有同样的活板门和梯子。小型营地 2 个入口、中型 3 个、大型 4 个。
- 巢穴只在最后一道工序开挖，会把同一高度上别的补方覆盖掉；顶板上再压一层夯土封死空腔余量。

地下横切示意图：[goblin_camp_lair.png](previews/goblin_camp_lair.png)（三档营地的牢笼层俯视，深浅色块是墙体、栅栏、干草和竖井）。

## 群体行为

| 行为 | 规则 |
| --- | --- |
| 求援 | 任意哥布林挨打后尖叫，32 格内的同族立刻锁定攻击者赶来，最多 24 只 |
| 首领召集 | 首领参战（或 32 格内有首领）后吹响战吼，100 格内的同族全部来作战，最多 48 只 |
| 萨满治疗 | 优先救血量低于 50% 的哥布林，一次回复目标 30% 最大生命并附加加速；没有重伤同族时才照顾结盟史莱姆 |
| 结盟史莱姆 | 毒、木（自然）、风、水四种元素史莱姆可以跟哥布林结盟：不打哥布林、跟着哥布林的目标一起上、不自己圈地盘 |
| 史莱姆驯服 | 聚落生成时会直接带 2～5 只成熟体盟军；萨满也会用 200 魔素把附近野生的这四种史莱姆收编（每只冷却 30 秒，附近最多 5 只） |
| 每日聚集 | 每天游戏时间 0:00～1:00，登记过营地的哥布林会走到聚集棚，互相看、冒爱心，并把背包里的一件东西递给同伴 |
| 幼崽成长 | 幼崽生成后 4～8 个游戏日成年，随机变成近战（50%）、弓箭手（30%）或萨满（20%），背包物品一起带过去 |

每只哥布林挨打后有 1 秒求援冷却，首领召集有 6 秒冷却，避免连击时反复扫描大范围实体。

## 注意事项

- 新版巢穴只在**尚未生成**的聚落里出现，旧存档已经生成的营地不会补挖地下室。
- 被关的村民和铁傀儡是困在栅栏里的，铁傀儡会隔着栅栏打哥布林，这是预期行为，不会拆墙。
- 梯子竖井是给玩家走的：哥布林不会爬梯子，正常情况下不会自己跑进地下巢穴。
- 已通过编译与离线布局自检（三档 × 三种地形，含分区块一致性、读档往返、牢笼与竖井连通检查）；
  完整模组组合下的实机交战仍建议复测。
