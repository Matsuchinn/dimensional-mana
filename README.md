# 次元物语：魔素（Dimensional Mana）1.3.3.1

一套给 Minecraft 1.21.1 加「魔法体系」的 NeoForge 模组：魔素与斗气、十二种元素、七十余个法术、元素反应与镀层、法杖饰品、魔晶工业、元素史莱姆、哥布林阵营、冒险者交易，以及一整套成就进度。

**1.3.3.1 版本迎来了模组迄今为止最具压迫感的机制 Boss「魔蚀凋零」，同时对模组底层 UI、多语言环境与流浪剑士 AI 进行了史诗级修复与重构。** 配合原有的「魔导」魔法阵系统，为你提供从自动化生产到硬核动作战斗的完整体验。

## 1.3.3.1 核心更新：魔蚀凋零与体验重构

### 全新史诗 Boss：魔蚀凋零
你可以在【魔晶加工台】用 1 万魔素侵蚀凋零骷髅头，并使用灵魂沙与**特级魔晶块**摆出仪式阵，召唤这个拥有 2000 点生命值的恐怖梦魇。
- **残暴机制**：拥有 1 秒冷却的“单次 1 点限伤”机制，强制要求玩家使用高频连击破盾。半血进入二阶段后，解锁破坏地形、禁疗真伤、全息幻影分身，以及蓄力 7 秒抽干环境魔素、造成当前生命值 90% 真伤的“虚无空灭射线”。
- **顶级光效**：完全抛弃原版马赛克粒子，采用纯几何平滑面片、自发光边缘、轨道二十面体晶体与空间扭曲面片构建大招特效。
- **专属声效**：混入 CC0 真实录音（巨兽低吼、地鸣等）合成 10 余条专属压迫感音效。
- **丰厚掉落**：必掉全新传说物品【畸变下界之星】。

### 全新中立 NPC：流浪剑士
- 携带强大剑术与斗气招架逻辑的中立 NPC。可用 64 金币雇佣一天。
- **AI 智能重构**：彻底修复了此前贴墙卡顿、原地打转的问题；现在能智能探测并跨越最高 3 格的障碍物，战斗走位更加丝滑致命。

### 底层 UI 与多语言修复（彻底解决 Text is messed up）
- **补齐 200 多条英文翻译**：此前英文环境下因缺键导致的显示原始代码（`item.xxx`）问题已被全面清除。
- **动态排版重构**：新增 UI 宽度自适应算法，所有界面（图鉴、轮盘、法阵台、机器面板）彻底告别英文文本过长导致的顶出边框、重叠压字问题。
- **中文硬编码清理**：指令帮助、角色角标等残留汉字已全面接入多语言系统。

## 核心玩法：魔导魔法阵

用**魔法阵绘制台基座**拼出阵盘，手持**魔导调试棒** Shift + 右键注册，进入绘制 UI。画布按基座数量扩展像素网格，你用粉末“画”出功能块，系统识别图案并吸附成标准节点。

- **输出节点双形态**：没有下游时作为【终端】直接释放效果（红石、治疗、伤害等七大协议）；连接下游时作为【前置】，将“元素×语义”编译成词缀喂给终端（如 火药+火 = 爆炸）。
- **条件节点门控与声明**：7种原版粉末（糖、紫水晶等）决定判定主域，12种元素过滤属性，组合出 **91 种逻辑判定**。此外，凡是涉及召唤数量、挖掘限额、PvP 开关等模糊边界，**必须插入条件节点进行声明，否则法阵报错锁死**。
- **零落地试运行**：Shift+右键锚点直接在聊天栏打印效果预览与边界缺失提醒，不消耗实体方块。
- **蓝图与法阵码**：`DM1-...` 短码分享，一键备料，抄作业极其方便。

- **双资源**：魔素施法，斗气减伤。包含凝聚斗气、完美招架、弹反与斗气技能树。
- **12 种元素**：火、水、冰、雷、风、土、木、金、光、毒、音 + 奥术；17 种元素反应。

- **生产**：五级魔晶、研磨器、魔锻炉、专业魔晶锻造炉、魔晶加工台；炉子背面贴加工台可把经验换成魔素。
- **元素镀层**：护甲每层 5% 元素抗性，盾牌每层 25% 完美格挡。
- **探索**：魔晶洞穴、远古魔法祭坛、元素史莱姆（12 种 × 3 档体型）、哥布林聚落与地下巢穴。

## 快速上手

1. **领书**：首次进入存档自动获得《万法知识之书》和《战斗手册》，按 **K** 打开。
2. **选元素**：第一次开书进入「元素共鸣」，从 11 种基础元素中选 3 种；奥术始终开放。
3. **攒魔素**：挖魔晶矿 → 磨粉 / 烧成魔晶，左下角球体就是魔素。
4. **学法术**：对应元素碎片 + 学派碎片开启「习得模式」，成功施放 3 次永久学会。
5. **装法术**：按住鼠标按键 5 打开快捷盘，鼠标按键 4 施放（键位可在控制中修改）。
6. **画法阵**：拼绘制台基座 → 调试棒注册 → 画节点 → 补条件声明 → 预览 → 刻印石板贴地运行。

前期路线：找魔晶矿 → 研磨器 + 魔晶加工台 → 攒碎片学第一个法术 → 用交易和宝箱补饰品 → 做一套镀层 → 画第一个火球阵 → 挑战魔蚀凋零。
