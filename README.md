# 次元物语：魔素（Dimensional Mana）

一套为 Minecraft 1.21.1 打造的**深度魔法与硬核战斗**综合模组。在这里，你不仅能研习七十多种法术、操控十二种元素，还能掌握斗气进行近战招架，甚至面对被彻底强化的原版生物与全新阵营。

游戏内自带详尽的《万法知识之书》与《战斗手册》，所有配方与机制均可随时查阅或查询WIKI。

### ✨ 核心特色

*   **双轨资源体系**：**魔素**（施法蓝条）与 **斗气**（战斗减伤护盾）双修。斗气不仅提供高额减伤，还能在战斗中自然恢复或主动凝聚。
*   **十二元素与法术**：12 种元素属性（含奥术），73 个可学可练的法术。利用元素附着触发 17 种反应（蒸发、超载、冻结等），还能给装备打上**元素镀层**，针对性地抵御特定属性伤害。
*   **硬核近战与招架**：主手拿剑副手空手，长按右键进入**斗气招架姿态**。精准弹反弓箭与近战，触发“完美招架”让敌人陷入巨大破绽。配合 15 级斗气等级与专属技能，打造纯物理剑士流派。
*   **全新生灵与阵营**：
    *   **12 种元素史莱姆**：分三档体型，会躲避克制元素，其中 5 种甚至可以被驯服成为你的坐骑或帮手。
    *   **哥布林阵营**：新增 5 种哥布林，拥有拾取装备、结群求援的 AI，并会生成包含地下巢穴的野外营地。
    *   **原版生物史诗级加强**：原版怪物也有了魔素、斗气和专属技能（如凋灵风暴、末影龙无限复活等），战斗更具挑战性（新增生物暴击系统）。
*   **海量养成与探索**：5 级魔晶矿与加工机器、23 件新增稀有度饰品、会交易的冒险者，以及完整的成就树。

### ⚙️ 运行环境
*   **游戏版本**：Minecraft 1.21.1
*   **加载器**：NeoForge 21.1 及以上
*   **必需前置**：Curios 9.5.1+
