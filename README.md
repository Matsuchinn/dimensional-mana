| 项目 | 要求 |

**安装步骤**

1. 给游戏装好 NeoForge 21.1（没装过的话，用 NeoForge 官方安装器，选 1.21.1）。

## 3. 快速上手

1. **领书**：第一次进服务器（或存档）时，会自动获得一本《万法知识之书》。按 **K** 打开；书放在背包或饰品栏时都能用。
2. **选元素**：第一次打开书会进入「元素共鸣」，从 11 种基础元素里**自选 3 种**（不可重复）。奥术不用选，始终开放。之后想解锁别的元素，可以研读古老魔法石碑或使用元素天赋卷轴。
3. **攒魔素**：挖魔晶矿 → 磨成粉 / 烧成魔晶；魔素是施法的「蓝条」，左下角球体就是它。
4. **学法术**：用 1 个对应元素碎片 + 1 个对应学派碎片开启「习得模式」，成功施放 3 次后永久学会。
5. **装上法术**：按住**鼠标中键**打开法术快捷盘（12 个槽位），选一个槽，再用**鼠标侧键**施放。所有键位都能在「选项 → 控制」里改。

前期最稳的路线：找魔晶矿 → 做研磨器和魔晶加工台 → 攒碎片学第一个法术 → 用交易和宝箱补齐饰品。

## 4. 魔素与斗气

### 魔素（施法资源）

- 左下角的球体显示魔素，会随时间自然恢复。
- **环境魔素浓度**会影响恢复速度：主世界平均 10、下界 8、末地 1；紫水晶洞穴至少 12，魔晶洞穴至少 15。
- 睡觉立刻恢复最大魔素的 50%（不会超过正常上限）。
- 魔素耗尽会进入**魔力枯竭**：停止自然回魔、受到的伤害 +30%、造成的伤害 -60%，需要缓一缓。
- 补魔剂可以恢复魔素，还能形成「超量魔素」；超过安全阈值会中毒，超量部分每秒衰减。

### 斗气（减伤层）

- 斗气是包在生命值外面的一层护盾：受到伤害时先扣斗气，再扣血。
- 斗气有上限，会缓慢回复；技能「斗气」每级提高 2% 上限。
- 两本附魔配合斗气：**斗气缠绕**（盔甲，最高 IV）提高斗气层数，**斗气破除**（武器，最高 V）攻击时无视目标一部分斗气。

## 5. 法术体系

### 5.1 元素与学派

**元素**决定「用什么能量」：火、水、冰、雷、风、土、木、金、光、毒、音，共 11 种基础元素，外加不占三选名额的**奥术**。

**学派**决定「法术做什么」，共 13 类：破灭（伤害）、守护（防护）、祝福（增益）、治愈（治疗）、诅咒（削弱）、束缚（控制）、迁跃（移动）、唤灵（召唤）、洞察（预言）、紊乱（混沌），以及预留的心灵、时序、挪移。

每个法术 = 一个元素 × 一个学派，所以既有火系伤害，也有水系治疗、风系移动、木系召唤这样的组合。

### 5.2 法术分级

| 分级 | 碎片要求 | 特点 |
| --- | --- | --- |
| 初级 | 下级元素碎片 + 下级学派碎片 | 消耗低、冷却短，基础输出与功能 |
| 中级 | 中级元素碎片 + 中级学派碎片 | 伤害或效果明显更强 |
| 高级 | 高级元素碎片 + 高级学派碎片 | 高消耗、长冷却，带法阵、充能或领域机制 |

奥术没有元素媒介，所以奥术法术用**同品级奥术碎片**代替元素碎片，再配一个同学派碎片。

碎片可以在魔晶加工台用「低一级碎片 + 魔晶粉」逐级升上去，也能从宝箱、游离女巫、冒险者和古老石碑处获得。

### 5.3 怎么学一个法术

1. 背包里带好对应品级的元素碎片与学派碎片。
2. 在万法知识之书的法术页选择目标法术，进入**习得模式**（会消耗碎片）。
3. 按施法键练习，**成功 3 次**后永久学会。失败只消耗魔素，进度保留。
4. 每学会一个新法术都会「顿悟」，永久增加基础魔素上限（初级 +48、中级 +96、高级 +192，重复学习同类只给较少的一份）。

### 5.4 施法操作

- 法术快捷盘有 **12 个槽位**，每槽放一个已学会的法术。
- 施法需要读条（前摇），读条期间被生物攻击会被打断。
- 部分法术支持**按住 Alt + 鼠标左键蓄力**（例如多重结界射线、炽阳之怒）。
- 「选定类」法术最远 16 格：右键选目标，左键确认；增益类可以对空选自己。

## 6. 元素附着与元素反应

法术命中会给目标挂上**元素附着**（头顶的小图标），不同元素互相碰上就会触发**元素反应**。共 17 种：

| 类别 | 反应 |
| --- | --- |
| 增幅 | 蒸发、融化 |
| 剧变 | 超载、感电、超导、激发 |
| 控制 | 冻结 |
| 充能 | 充能 |
| 持续 | 燃烧、腐化 |
| 扩散 | 扩散 |
| 次级 | 泥沼、蔓延、熔炼、净化、震荡、致盲 |

- 反应伤害会吃到「元素伤害加成」和「反应伤害加成」两类饰品属性。
- 同一目标同时满足多个反应时，按「增幅 → 剧变 → 控制 → 充能 → 持续 → 扩散 → 次级」的优先级结算。
- 附着时长受元素精通类饰品影响，例如元素结晶戒指会同时提高对应元素的伤害、附着时长和反应伤害。

## 7. 魔法成长：等级、技能与顿悟

- **魔法等级**上限 15 级，靠累积「魔法经验」升级：每次成功施法 +1；打怪、交易等拿到的原版经验球会按约 4:1 换成魔法经验；魔素达到里程碑也会奖励经验。
- 每升一级发**技能点**，等级越高发得越多。
- 共 8 项可加点技能，每项上限 20 级：

| 技能 | 每级效果 |
| --- | --- |
| 魔素 | 魔素上限 +2% |
| 斗气 | 斗气上限 +2% |
| 法术抗性 | 受到法术伤害 -2% |
| 魔素强度 | 法术强度 +6 |
| 施法速度 | 施法速度 +3% |
| 法术暴击率 | 暴击率 +1% |
| 法术暴击伤害 | 暴击伤害 +2.5% |
| 魔力消耗减免 | 魔素消耗 -2% |

- 加点消耗：1~3 级每级 1 点，4~6 级 2 点，7~9 级 3 点，10~20 级 4 点。
- 加错了？用**魔法技能忏悔石**（消耗 200 魔素）重置，已花技能点全部返还。
- 魔素上限达到 200 / 500 / 1000 / 2000 / 5000 / 10000 时还会额外奖励魔法经验。

通用法杖分 5 级（初级 / 中级 / 高级 / 极致 / 特级），提供法术伤害、魔素强度、施法速度、魔素消耗、魔素恢复等加成。**双持只取较高的一把**，不会简单叠加。

| --- | --- | --- |

| 魔法集中披风 | 背饰 / 胸甲位 | 魔素强度 +32，施法时长 -18%，魔素消耗 -8%，暴击率 +5% |
| 伤害偏转披风 | 背饰 / 胸甲位 | 魔素强度 +64，魔法减伤 25%，反弹 45% 伤害 |
| 魔法大师披风 | 背饰 / 胸甲位 | 魔素强度 +128，魔素上限 +25%，暴击伤害 +45%，45% 概率生成魔素凝聚球 |

## 9. 魔晶、材料与机器

### 魔晶五级

| 品质 | 魔素含量 |
| --- | --- |
| 下级魔晶 | 100 |
| 中级魔晶 | 400 |
| 高级魔晶 | 1600 |
| 极品魔晶 | 4000 |
| 特级魔晶 | 12000 |

- 地下会生成魔晶矿；**魔晶洞穴**里矿更密，还会少量生成特级魔晶簇。
- 原矿需要烧炼成成品，精准采集可以直接拿到矿物方块。
- 成品魔晶用**研磨器 + 杵**磨成 4 份同级魔晶粉；青金石磨 6 粉、紫水晶碎片磨 2 粉。

### 主要机器

| 机器 | 用途 |
| --- | --- |
| 魔晶加工台 | 重组魔晶、升级碎片、制作元素结晶/戒指/魔力布匹等魔法制品，消耗魔素和时间 |
| 研磨器（木/石/金/铁/钻石/下界合金） | 魔晶磨粉、青金石与紫水晶磨粉 |
| 魔锻炉 | 8 个哭泣黑曜石 + 1 个中级魔晶；烧炼速度是原版熔炉的 80% |
| 专业魔晶炼制炉 | 高级机器，烧炼速度 30%，可把魔晶逐级炼成魔晶粉、烧制特级魔精钢 |

两台炉子都能用原版燃料，也兼容原版和其他模组的普通熔炼配方。

### 药剂与工具

- **补魔剂**（下 / 中 / 高 / 特级）：恢复魔素并允许超量；用酿造台以「浓稠药水 + 魔晶粉」起步。
- **纯态液态魔晶**：恢复 300% 最大魔素，但会获得 180 秒凋零，喝之前想清楚。
- **剧毒Ⅲ药水**：特级魔晶粉 + 剧毒Ⅱ药水在酿造台酿造。
- **鉴定球**：右键查看自己的魔素和斗气。
- **魔素检测器**：蓄力 3 秒消耗 10 魔素，显示当前区块浓度和最近洞穴。
- **鉴定眼镜**：戴在头饰栏，准心旁显示区块浓度和目标信息，每秒消耗 0.4 魔素。

### 其他材料

魔力布匹、魔法绸缎、粗制 / 精致 / 通用魔构件、元素结晶、元素 / 学派 / 奥术碎片、天赋卷轴、远古魔导残片、超导魔晶粉末、超导魔晶、远古魔钢钢坯、特级魔精钢、空白法术卷轴等，都是合成链上的中间材料。

### 创造模式物品栏

创造模式里有「次元物语：魔素」和「次元物语：魔法」两个物品栏。「魔法」页把戒指、护符、披风、手套、共鸣核心等饰品排在最前，然后是通用法杖、刷怪蛋，最后才是碎片、天赋卷轴和材料，找东西不用翻半天。

## 10. 探索、结构与生物

### 世界生成

- **魔晶矿脉**：主世界地下分层生成下 / 中 / 高 / 极品魔晶矿。
- **魔晶洞穴**：高浓度魔素洞穴，矿更密，偶尔有特级魔晶簇，用检测器可以找。
- **远古魔法祭坛**：会在部分生物群系生成的小型结构，有宝箱、守卫和**古老魔法石碑**。在石碑处研读可以解锁新的元素法术。

### 生物

| 生物 | 说明 |
| --- | --- |
| 冒险者 | 中立，会往村庄走；右键交易，也会帮你打怪 |
| 游离女巫 | 会施法的敌对女巫，掉落魔法绸缎、碎片等材料 |
| 召唤物 | 藤蔓仆从、飞剑、毒藤触手、寒冰傀儡，以及披风生成的魔素凝聚球 |

## 11. 冒险者交易

- 冒险者会出现在村庄附近，也能用刷怪蛋召唤；**右键**打开交易界面。
- 每次刷新挂 **10 笔**交易，按品级抽：

| 品级 | 概率 | 每笔可买次数 |
| --- | --- | --- |
| 初级（T1） | 40% | 5~8 次 |
| 中级（T2） | 30% | 4~6 次 |
| 高级（T3） | 20% | 2~4 次 |
| 稀有（T4） | 8% | 1~2 次 |
| 传说（T5） | 2% | 1 次 |

- 每笔交易横排三格：前两格是你要付的材料，最右一格是成品，外框颜色代表品级。
- 点成品格成交，成交给原版经验，品级越高给得越多。
- 冒险者在村庄住下后，每过一天（24000 刻）重新抽交易池并重置次数。
- 看货时他会站住不动；走出 8 格以外界面自动关闭。

## 12. 成就与进度

打开进度界面（默认 **L** 键）会看到两条主树：

- **万法启蒙**：万法知识之书、魔法等级 1/5/10/15、魔素 200/500/1000/2000/5000/10000 六档里程碑。
- **元素反应**：各种元素反应的首次触发与收集。

## 14. 常见问题

**Q：进游戏没看到魔素球？**
A：确认已装 Curios，且 jar 放进了 `mods` 文件夹；主菜单左下角要能看到 NeoForge。

**Q：法术列表是灰的 / 学不了？**
A：第一次打开书先选 3 种元素；未解锁元素显示锁定。学会法术需要对应元素碎片 + 学派碎片，并成功施放 3 次。

**Q：魔素一直不恢复？**
A：可能处于「魔力枯竭」，等状态结束，或者喝补魔剂。环境魔素浓度低也会变慢。

**Q：饰品戴不上？**
A：饰品需要 Curios 提供的对应栏位（戒指、护符、背饰、手饰、魔法饰品）。

**Q：旧版本存档能直接用吗？**
A：可以，替换 jar 即可，不要同时放新旧两个版本。
