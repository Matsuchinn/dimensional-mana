# 次元物语：魔素（Dimensional Mana）1.3.1 Beta

一套给 Minecraft 1.21.1 加「魔法体系」的 NeoForge 模组：魔素与斗气、十二种元素、七十余个法术、元素反应与镀层、法杖饰品、魔晶工业、元素史莱姆、哥布林阵营、冒险者交易，以及一整套成就进度。

**1.3.1 Beta 的核心是「魔导」——一套画出来、就能跑起来的魔法阵系统。** 你把节点画在绘制台上，用粉末定义它做什么，条件节点声明边界，刻印成石板贴到方块表面，法阵就会按你的设计持续运转。

> **AI 使用声明**：本模组在开发过程中使用了 AI 辅助完成部分代码、文档与文本内容，所有内容均由作者审核、修改并负责。

## 1.3.1 Beta 核心：魔导魔法阵

### 从画布到法阵

用**魔法阵绘制台基座**拼出阵盘（2×2、3×3 或更大），手持**魔导调试棒** Shift + 右键注册，进入绘制 UI。画布按基座数量扩展像素网格，你用粉末“画”出功能块，系统识别图案并吸附成标准节点。

### 输出节点：终端与前置

输出节点有两种身份，由连接关系自动判定：

- **终端**：没有下游输出时，直接执行效果。按语义粉末走七大协议——**红石→信号、糖→生命、火药→伤害、烈焰→净化、萤石→照明、青金→扫描、紫晶→充能**。
- **前置**：连接了下游输出时，自身不结算，而是把「元素 × 语义」编译成**词缀**，喂给终端。比如糖+木编译出「友好生物召唤」，火药+火编译出「爆炸」。

硬规矩会红字拦截：词缀不许套娃（E-PREFIX-CHAIN）、一个前置只喂一个终端（E-PREFIX-FORK）、声明条件只服务一个终端（E-COND-MULTI）。

### 条件节点：门控与声明

条件节点是法阵的“边界声明板”，有两种形态：

**门控模式**——判断 True/False，放行或拦截。7 种原版粉末决定主域（糖=生命、紫水晶=资源、青金石=状态/标签、萤石=环境、红石=动作/空间、火药=数量、烈焰=元素附着），12 种元素做属性过滤，染料 0~15 档设定阈值，UI 的 `⇌` 切换大于/小于。7×13 组合出 **91 种逻辑判定**，覆盖“周围 8 格内燃烧的敌对生物 ≥3 只”“目标生命 ≤30% 且正在举盾”这类硬核条件。

**声明模式**——不拦截信号，只声明边界参数。召唤数量与寿命、挖掘每分钟限额、传送最大距离、PvP 开关、扫描隐私权限、红石无线距离——**凡是可能产生模糊边界的地方，没有对应声明节点就 E1 报错，禁止启动**。声明的参数在染料档位区间内用滑条/下拉微调，低功率只能粗选，超导才能精调。

### 触发节点与拓扑

触发节点支持**独立运行**和**底座模式**。当条件节点放在触发节点上游作为前置判定时，触发节点退化为逻辑起点，只保留效率加成；条件在下游时，触发节点照常工作，把信号交给门控做二次判定。

### 效果预览

调试棒 Shift + 右键刻印锚点，**什么都不落地**，只在聊天栏逐条打印效果预览：

—— 效果预览（试运行，不落地）——
终端#4（火药+火）：预计每发 7.5 点（火系，可打反应）× 约 3 个目标 · 词缀：爆炸
  ↳ 爆炸词缀：中心 1.5 格爆炸（默认不破坏方块，声明「方块破坏」才拆地）
成本参考：启动 46 / 维持 6 / 触发 18 魔素

缺什么声明直接点名，照着红字补条件节点就能修好阵。

### 蓝图与法阵码

- **教学蓝图**：火球阵、治疗阵、护盾阵、采矿阵、立体火墙，以「残破的蓝图」形式散落在村庄、女巫掉落、魔晶洞穴、远古祭坛和冒险者交易中。放进绘制台可反复“拆解研究”。
- **法阵码**：`DM1-...` 短码，Base64 + DEFLATE 压缩，带作者与蓝图名，导入前预览材料清单，支持一键备料。v1 旧码照常读取，v2 码携带声明参数。

## 其他内容速览

- **双资源**：魔素施法，斗气减伤。凝聚斗气（Alt + Z）、招架与完美招架、斗气技能树。
- **12 种元素**：火、水、冰、雷、风、土、木、金、光、毒、音 + 奥术；17 种元素反应。
- **73 个法术**：元素 × 学派，初级 / 中级 / 高级；魔法等级 15 级，8 项可加点技能。
- **装备**：5 级法杖；Curios 饰品涵盖元素结晶戒指、披风、护符、手套、共鸣核心等。
- **生产**：五级魔晶、研磨器、魔锻炉、专业魔晶锻造炉、魔晶加工台；炉子背面贴加工台可把经验换成魔素。
- **元素镀层**：护甲每层 5% 元素抗性，盾牌每层 25% 完美格挡。
- **探索**：魔晶洞穴、远古魔法祭坛、元素史莱姆（12 种 × 3 档体型）、哥布林聚落与地下巢穴。
- **交易**：冒险者 5 个品级，38 条交易池，每天刷新。
- **成就**：59 个进度节点，两条主树，自动判定。

## 快速上手

1. **领书**：首次进入存档自动获得《万法知识之书》和《战斗手册》，按 **K** 打开。
2. **选元素**：第一次开书进入「元素共鸣」，从 11 种基础元素中选 3 种；奥术始终开放。
3. **攒魔素**：挖魔晶矿 → 磨粉 / 烧成魔晶，左下角球体就是魔素。
4. **学法术**：对应元素碎片 + 学派碎片开启「习得模式」，成功施放 3 次永久学会。
5. **装法术**：按住鼠标按键 5 打开快捷盘，鼠标按键 4 施放（键位可在控制中修改）。
6. **画法阵**：拼绘制台基座 → 调试棒注册 → 画节点 → 补条件声明 → 预览 → 刻印石板贴地运行。

前期路线：找魔晶矿 → 研磨器 + 魔晶加工台 → 攒碎片学第一个法术 → 用交易和宝箱补饰品 → 做一套镀层 → 画第一个火球阵。
