# 次元物语：魔素（Dimensional Mana）

一套给 Minecraft 1.21.1 加「魔法体系」的 NeoForge 模组：魔素与斗气两种资源、十二种元素属性、七十多个可学可练的法术、元素附着与元素反应、元素镀层防护、法杖和饰品、魔晶加工与炼制机器、十二种元素史莱姆、会交易的冒险者，以及一整套成就进度。

游戏内有一本《万法知识之书》，规则、配方和数值都能在书里查到。本 README 只带你快速认识这个模组；完整内容见wiki。

> **AI 使用声明**：本模组在开发过程中使用了 AI 辅助完成部分代码、文档与文本内容，所有内容均由作者审核、修改并负责。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| Minecraft | 1.21.1 |
| 加载器 | NeoForge 21.1 及以上 |
| 必需前置 | **Curios 9.5.1+** |
| 可选前置 | JEI 19.64+（查配方用） |

把 **Curios** 和本模组的 `dimensional_mana-1.1.1.jar` 一起放进 `mods` 文件夹即可。不要同时放多个旧版本 jar；旧存档可以直接替换 jar 继续玩。

## 快速上手

1. **领书**：首次进入存档会自动获得《万法知识之书》，按 **K** 打开。
2. **选元素**：第一次打开书会进入「元素共鸣」，从 11 种基础元素中自选 3 种；奥术始终开放。
3. **攒魔素**：挖魔晶矿 → 磨粉 / 烧成魔晶。左下角球体就是魔素。
4. **学法术**：用对应元素碎片 + 学派碎片开启「习得模式」，成功施放 3 次后永久学会。
5. **装法术**：按住**鼠标中键**打开法术快捷盘，用**鼠标侧键**施放。键位可在「选项 → 控制」修改。
6. **加防护**：攒到元素结晶粉末后，可在魔晶加工台给护甲和盾牌做**元素镀层**，针对不同 Boss 换装。

前期路线：找魔晶矿 → 做研磨器和魔晶加工台 → 攒碎片学第一个法术 → 用交易和宝箱补齐饰品 → 做一套镀层去打元素史莱姆。

## 核心内容速览

- **双资源**：魔素用于施法，斗气作为减伤护盾；静止时按 **Alt + Z** 可凝聚斗气。
- **12 种元素**：火、水、冰、雷、风、土、木、金、光、毒、音 + 奥术。
- **73 个法术**：分初级 / 中级 / 高级，由「元素 × 学派」组合而成；「魔素感知」可隔墙标出魔晶矿与高魔素生物。
- **17 种元素反应**：增幅、剧变、控制、充能、持续、扩散、次级等。
- **成长系统**：魔法等级上限 15 级，8 项可加点技能，学会新法术会「顿悟」提升魔素上限。
- **装备**：5 级通用法杖；Curios 饰品包括元素结晶戒指、披风、护符、手套、共鸣核心等。
- **生产**：魔晶五级、研磨器、魔锻炉、专业魔晶锻造炉、魔晶加工台；炉子背面贴加工台可把经验换成魔素。
- **元素镀层**：护甲每层 +5% 对应元素抗性，盾牌每层 25% 完美格挡；砂轮可拆除并返还粉末。
- **元素史莱姆**：12 种元素、3 档体型，部分可驯服（金 / 土 / 风 / 音 / 魔素）。
- **探索与交易**：魔晶洞穴、远古魔法祭坛、古老魔法石碑、冒险者交易（5 个品级）。
- **成就**：59 个进度节点，两条主进度树，全部自动判定。
