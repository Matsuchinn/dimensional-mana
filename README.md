# 次元物语：魔素（Dimensional Mana）1.4.0 ·  README

一套给 Minecraft 1.21.1 的 NeoForge 魔法模组：魔素与斗气、12 元素、73 法术、元素反应、魔法阵、魔晶工业、生物阵营、冒险者交易与成就进度。

**1.4.0 核心新增：武备词条与装备评级。** 野外掉落的武器 / 护甲自带 C~SSS 词条，可打铁升级、洗练、同类合并，最终做成毕业级【魔精钢】系列；同时保留完整的「魔导」魔法阵系统。

## 1.4.0 新增内容

### 武备词条与评级
- 掉落评级：主世界 C~B；下界 C~A；末地 A~SSS；远古城市 / 神殿 B~S。
- 词条上限：主词条最高 12 级，副词条最高 +4 级；主词条在 3 / 6 / 9 / 12 级触发副词条成长。
- 流派偏好：原版武器 80% 物理 / 20% 魔法；防具 60% / 40%；工具 100% 物理；法杖与布甲 100% 魔法；魔精钢 50% / 50%。
- 品质前缀：破损的 → 普通的 → 精良的 → 稀有的 → 史诗的 → 传说的。

### 新机器
- **武备加工台**：给装备打铁升级词条；消耗 `2^N + 100N` 魔素，材料格只吃 1 个魔晶，溢出魔素按 50% 找零。
- **魔晶铁砧**：同类词条合并；3 特级魔晶块 + 4 铁块 + 1 铁砧合成，永不损坏。

### 魔精钢毕业装备
- 下界合金装备 + 魔精钢锻造模板，在魔晶加工台消耗 5000 魔素 / 100 秒升级。
- 模板来源：末地飞船 / 城 15%，魔蚀凋零 50%。
- 附魔等级结算额外 +1；工具耐久 4062，基础挖掘速度 12。

### 其他更新
- **魔蚀凋零强化**：血量 5120，光斑射线持续 4 秒后每秒追加 1000 真实伤害，每 1.25 秒发射凋零骷髅头。
- **元素附着免疫限制更新**：元素附着与高级魔法状态不再受原版药水免疫限制，可强制作用于凋零、末影龙及其他模组免疫怪。

## 魔导魔法阵（保留）

铺绘制台基座 → 调试棒注册 → 画节点 → 塞粉末 → 条件节点声明边界 → 预览 → 刻印石板贴面 → 启动。

- **终端**：无下游时直接执行，七大协议：红石信号 / 糖生命 / 火药伤害 / 烈焰净化 / 萤石照明 / 青金扫描 / 紫晶充能。
- **前置**：连接下游时编译词缀，如糖+木=友好召唤，火药+火=爆炸。
- **条件节点**：门控模式做 7×13=91 种逻辑判定；声明模式缺边界直接 E1 报错禁止启动。
- **法阵码**：`DM1-...` 短码，支持导入预览与一键备料。

## 快速上手

1. 领《万法知识之书》与《战斗手册》，按 **K** 开书。
2. 首次开书选 3 种基础元素，奥术始终开放。
3. 挖魔晶矿 → 磨粉 / 烧魔晶 → 攒魔素。
4. 元素碎片 + 学派碎片开启习得模式，成功施放 3 次学会法术。
5. 鼠标中键打开法术快捷盘，鼠标侧键施放。
6. 画第一个火球阵：基座 → 注册 → 画节点 → 补声明 → 预览 → 刻印启动。
7. 1.4.0 刷词条：开宝箱 / 打怪拿 C~SSS 装备 → 武备加工台升级 → 超导魔晶洗练 → 魔晶铁砧合并 → 魔精钢毕业。
